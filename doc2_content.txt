Why GHL Native?
All 7 LUME automations run inside GHL Workflows — no external webhooks, no n8n middleware, no API keys. Triggers, conditions, SMS, email, tags, stage changes, tasks, delays, and notifications all happen internally with zero latency.

How to Create a Workflow in GHL
1. Log into GHL → Select LUME sub-account
2. Left sidebar → Automation → Workflows
3. Click + Create Workflow → Start from Scratch
4. Name the workflow (e.g., W01 — Meta Ad Speed-to-Lead)
5. Click Add New Trigger → select the trigger type
6. Configure trigger filters
7. Add actions sequentially (click + after each action)
8. Save → Publish (toggle ON)

W01: Meta Ad Speed-to-Lead (~5 min)
Purpose: Instantly engage new leads from Meta ads — SMS + opportunity + task within seconds.

TRIGGER:
• Type: Contact Created
• Filter: Contact Tag → contains → lume-meta-ad

ACTION 1 — Send SMS
• Message: Hi {{contact.first_name}}, thanks for your interest in LUME! Our team will call you within 15 minutes.

ACTION 2 — Add Tag
• Tag: lume-new

ACTION 3 — Create Opportunity
• Pipeline: LUME — Lead to Member (jpwo4D5y1g1462CvxrXn)
• Stage: New Lead (b73a59f7-42f6-4939-a71f-266c487c3443)
• Name: {{contact.name}} — Meta Lead
• Source: Meta Ads

ACTION 4 — Assign User (Round-Robin)
• Type: Round Robin
• Users: Jashree, Mega

ACTION 5 — Create Task
• Title: Call new Meta lead — {{contact.name}}
• Due: 15 minutes from now
• Assign: Round-robin assigned user

ACTION 6 — Internal Notification
• Notify: Assigned user
• Message: New LUME lead: {{contact.name}} — {{contact.phone}}. Call NOW.

W04: No-Show Recovery (~8 min)
Purpose: Re-engage no-shows with 3-touch SMS recovery over 48 hours.

TRIGGER:
• Type: Appointment Status Changed
• Filter: Status = No Show

ACTION 1 — Send SMS (Immediate)
• Message: Hi {{contact.first_name}}, we missed you for our scheduled call. No worries — would you like to reschedule? Here's our calendar: https://thelumeproject.com/book

ACTION 2 — Add Tag
• Tag: lume-no-show

ACTION 3 — Create Task (Urgent)
• Title: No-show recovery — {{contact.name}}
• Due: Now (immediate)
• Assign: Original assigned rep
• Priority: Urgent

ACTION 4 — Wait
• Duration: 24 hours

ACTION 5 — Send SMS (Follow-Up 1)
• Message: Hi {{contact.first_name}}, just following up. Would love to find a time that works better for you.

ACTION 6 — Wait
• Duration: 24 hours

ACTION 7 — Send SMS (Final)
• Message: Last check-in — if you'd still like to explore LUME, we're here. Just reply to reschedule.

ACTION 8 — If/Else: Contact Replied?
• Condition: Contact replied (check last message activity)
→ IF YES: Add tag lume-rescheduled
→ IF NO: Add tag lume-cold
